# 最近两次牛市：最大涨幅超过 500% 的股票

## 口径

- 牛市区间沿用 `scripts/market_regimes.py` 的固定定义：2019-02-01—2021-11-29、2024-09-23—2026-06-30，边界包含。
- 主口径最大涨幅 =（区间内某日后复权最高价 ÷ 此前交易日的最低后复权价 − 1）× 100%，要求低点严格早于高点；同日高低价的盘中顺序无法由日线确认，故不纳入该日配对。
- 对照口径为区间首个有效交易日后复权收盘至全区间后复权最高价。
- 股票从区间内首个有效交易日开始计算，因此包含区间内新上市股票；阈值为严格大于 500%。
- 行业使用 Baostock 在对应牛市结束日可查询到的证监会行业分类快照；缺失时保留通达信行业代码。两者为不同分类体系，代码不等于证监会行业名称。
