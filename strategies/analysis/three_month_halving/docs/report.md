# 下跌前起点创两年新高：腰斩后表现分布

数据截止 2026-09-30。符合条件的事件 1,166 个，其中具有完整 T+25 窗口的样本 1,156 个。

## 研究口径

- 腰斩信号 T0：个股先有完整前 63 根日线，当日后复权收盘价首次严格低于这段区间最高后复权收盘价的一半。相邻入选事件至少间隔同样多的个股交易日。
- 下跌前起点：T0 前 63 根个股日线内最高后复权收盘价所在日。阶段下跌期间允许反弹。
- 起点须有此前完整 504 根个股日线，其后复权收盘价严格高于这些日线的最高后复权收盘价。起点当天不参与历史基准；历史不足两年的事件不纳入筛选。
- 最高点涨幅取 T+1 至 T+25 最高后复权价，终点收益取 T+25 后复权收盘价，均除以 T0 后复权收盘价再减 1。T+25 按个股交易日计算，停牌日不计；只统计完整窗口。

## 解读边界

起点由事后形成的腰斩区间识别。窗口最高价也是事后可见的盘中极值，不是可预先锁定的卖出价；两种收益均未计实际买卖价格与费用。已退市或数据末尾不足 T+25 日线的事件不进入收益分布。
